# 🎬 Kareem Ahmed - Video Editor & Motion Graphics Portfolio

بورتفوليو احترافي لمونتير الفيديو والموشن جرافيك **كريم أحمد عبد العزيز**.

## 🌟 المميزات
- **معرض أعمال متكامل**: عرض أعمال الفيديو (إعلانات، ريلز، موشن جرافيك، وتصوير فوتوغرافي) بجودة عالية وتضمين YouTube و Behance.
- **Dark & Light Mode**: دعم كامل للتبديل السلس بين الوضع المظلم والمضيء مع حفظ التفضيل تلقائياً.
- **Smooth Inertial Scrolling**: تمرير سلس وانسيابي باستخدام مكتبة Lenis بفيزياء تحاكي أجهزة Apple iOS.
- **Arabic Typography**: خط **Cairo** المتميز في جميع عناصر الموقع.
- **تواصل فوري**: ربط مباشر بالواتساب ونموذج إرسال رسائل على البريد الإلكتروني.

## 🛠️ التقنيات المستخدمة
- **React 18 + TypeScript + Vite**
- **Tailwind CSS**
- **Framer Motion**
- **Lenis Smooth Scroll**
- **Lucide Icons**
